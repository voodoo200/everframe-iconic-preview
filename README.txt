ВСТРОЕННЫЙ ПОИСК ЛЮДЕЙ В CRM — ТОЛЬКО ТЕСТОВЫЙ РЕПОЗИТОРИЙ
voodoo200/everframe-iconic-preview

1. Заменить index.html, style.css, app.js в тестовом репозитории.
2. Сохранить старый config.js БЕЗ изменений.
3. Открыть тестовую CRM и найти в левом меню «Поиск клиентов».
4. Указать профессию, город, Instagram; нажать «Найти публичные профили».
5. Открыть Google/Яндекс/Bing, проверить человека, заполнить поля.
6. «Сохранить в CRM» создаёт реальную запись contacts в Supabase.
7. В конце откроется обычная карточка контакта, доступная для истории и задач.

ВАЖНО:
- Поиск открывает поисковую выдачу в отдельной вкладке, НЕ извлекает профили
  автоматически и НЕ делает массовый скрапинг Instagram.
- Вымышленных кандидатов и оценок вероятности покупки нет.
- Новые записи сразу сохраняются в общей Supabase БД: тестовая CRM НЕ песочница данных.
- Права Supabase RLS остаются действующими. service_role не нужен.
- Не изменяет рабочий репозиторий everframe-iconic-app.
- Проверено статически, но не выполнено end-to-end тестирование в живой CRM.
