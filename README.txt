EVERFRAME ICONIC CRM — единая обновлённая тестовая сборка

Только для репозитория everframe-iconic-preview. Рабочую CRM Елены не заменять до проверки.

Установка: замените в тестовом репозитории index.html, style.css и app.js. Существующий config.js оставьте без изменений. SQL не требуется.

Что изменилось: переработана вся композиция рабочего стола, шрифты, боковое меню, метрики, баннер, фильтры, строки контактов и профиль. На большом экране при наличии контактов профиль первого контакта открывается автоматически справа; на мобильном — по нажатию на контакт. Сохранены авторизация, поиск, редактирование, история и задачи. Исправлено повторное создание Supabase-клиента при входе.

Ограничения: это тестовая сборка, не проверенная в браузере с реальной Supabase. Фото — HTTPS URL, загрузки изображений нет. Данные в базе настоящие. Счётчик действий основан на contacts.next. Из художественного макета НЕ реализованы отдельные события, аналитика, уведомления и файлы. При одном контакте интерфейс не будет содержать вымышленных профилей.
